# Shortage.Global Frontend

https://frontend-ij85f.ondigitalocean.app/

## Development

#### Run development server

```
npm run dev
```

You will need running [backend](https://github.com/ShortageGlobal/shortage-global-backend).

#### Check types

```
npm run type-check
```

#### Run eslint

```
npm run lint
```

#### Run tests

```
npm test
```

## Deploy

```
npm run build
npm start
```

Read more: https://nextjs.org/docs/deployment#nodejs-server
